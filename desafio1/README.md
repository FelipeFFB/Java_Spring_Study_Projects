# Java_Spring_Study_Projects - Desafio 1

Projeto em Java (versão 25) utilizando o gerenciador de dependências Maven e o framework Spring Boot (versão 4.1.1) com a dependência Spring Web.
Neste primeiro projeto, aprendi a:

- Criar um projeto Spring Boot;

- Configurar componentes Spring (utilizando a anotação @Service para componentes de serviço);
  
- Utilizar injeção de dependência (através da anotação @Autowired);

- Implementar projeto de componentes.
