# Java_Spring_Study_Projects - Desafio 2

Projeto em Java (versão 25) utilizando o gerenciador de dependências Maven e o framework Spring Boot (versão 4.1.1) com as dependências Spring Web, Spring Data JPA e H2 Database.
Neste segundo projeto, aprendi a:

- Implementar entidades de domínio;

- Fazer o mapeamento objeto-relacional com JPA;
  
- Fazer o setup de um projeto Spring Boot para banco H2;

- Fazer o seeding de base de dados H2.
